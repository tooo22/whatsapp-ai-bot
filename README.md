# WhatsApp AI Bot (Render 24/7)

Bot WhatsApp AI berbasis Baileys dan Rootly AI Model API (`GLM-5.3-Flash`, `MiniMax-M2.7`, `DeepSeek-V4-Flash`), dirancang khusus untuk deployment gratis di Render.

## Fitur
- **Web QR Scanner:** Tampilan web interaktif untuk scan QR code WhatsApp langsung dari browser HP tanpa butuh akses terminal.
- **Support Chat Pribadi & Grup:** Membalas langsung di DM dan merespons saat di-mention (@tag) di grup WhatsApp.
- **Smart AI Model:** Terhubung ke Rootly API dengan auto-fallback prioritas.
- **Uptime Keep-Alive:** Menyediakan endpoint `/ping` dan `/health` agar bot bisa di-keep awake 24/7.
